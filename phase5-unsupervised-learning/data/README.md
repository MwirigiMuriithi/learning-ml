# 🗂️ Data dictionary

All datasets are **synthetic**, generated by `../scripts/generate_datasets.py` (fixed seed 42+), modelled on Kenyan retail and agriculture. Regenerate any time with `python scripts/generate_datasets.py`. No real person, farm or market is described.

## retail_customers.csv (800 rows)
| Column | Meaning |
|---|---|
| customer_id | Unique id |
| age, gender | Demographics (F/M) |
| annual_income_kes_k | Income, thousand KES *(12 missing)* |
| recency_days | Days since last purchase |
| orders_per_year | Orders in past 12 months |
| avg_basket_kes | Average basket value (KES) |
| discount_share | Share of purchases on promotion (0-1) |
| prefers_online | 1 = mostly online |
| annual_spend_kes | orders × basket |
| spending_score | 1-100 score derived from spend rank and recency (a derived column: think before using) |

## farmers.csv (700 rows)
| Column | Meaning |
|---|---|
| farmer_id, county, primary_crop | Identifiers/categories (15 counties, 16 crops) |
| farm_size_acres | Land area *(a few extreme values planted as outliers)* |
| yield_bags_per_acre | Yield |
| fertilizer_kg_per_acre | Fertiliser use *(15 missing)* |
| irrigated, improved_seed, coop_member | 0/1 flags |
| labour_days_per_acre | Labour intensity |
| distance_to_market_km | Distance to market *(6 missing)* |
| post_harvest_loss_pct | % lost after harvest *(10 missing)* |
| experience_years, extension_visits_per_year | Farmer experience and extension contact |
| annual_revenue_kes | ≈ size × yield × price × (1 − loss): an *outcome* |

## markets.csv (103 rows)
| Column | Meaning |
|---|---|
| market_id, market_name, nearest_hub | Identifiers (`nearest_hub` = "(none)" for 7 remote markets) |
| latitude, longitude | Location in degrees |
| avg_daily_traders, avg_daily_volume_tonnes | Scale |
| price_volatility | Coefficient of variation of prices |
| distance_to_city_km, road_quality_1_5 | Connectivity |
| has_cold_storage | 0/1 |
| perishable_share, n_commodities | Product mix |
| mobile_payment_share | Share of mobile-money payments |
| market_days_per_week | Activity |

## products.csv (48 rows)
| Column | Meaning |
|---|---|
| product | Commodity (e.g. Maize, Tomatoes, Tea, Milk) |
| avg_price_kes_per_kg, price_cv | Price level and volatility |
| seasonality_amplitude | Size of seasonal swings |
| shelf_life_days | Storage life |
| demand_elasticity | Price sensitivity of demand |
| wholesale_share, export_share | Channel mix |
| avg_margin_pct | Trader margin |
| monthly_volume_tonnes, markets_traded_in | Volume and reach |

## grocery_baskets.csv (2,500 baskets) · agro_input_baskets.csv (3,000 baskets)
Long format: one row per `(transaction_id, item)`. Convert with `df.groupby("transaction_id")["item"].apply(list)`.
Grocery: 24 items (bread, milk, maize flour, diapers…). Agro-dealer: 22 inputs (DAP, CAN, hybrid maize seed, pesticide, dairy meal…).

## 🔒 *_truth.csv (the answer keys)
`retail_customers_truth.csv` (6 true segments), `farmers_truth.csv` (5), `markets_truth.csv` (4 market types), `products_truth.csv` (7 categories).
**Use only in the 🔓 Reveal sections, after you have committed to your own answer.** In real life these do not exist.

### Planted structure (for instructors)
| Dataset | Hidden structure |
|---|---|
| retail_customers | Loyal Big Spenders · Bargain Hunters · Young Trendy · Wealthy Occasional · Frugal Savers · Lapsed Customers |
| farmers | Subsistence Smallholder · Commercial Grain · Intensive Horticulture · Dairy-Mixed · Emerging Market-Oriented (the deliberately blurry middle) |
| markets | Urban Wholesale Hub · Regional Aggregation · Rural Periodic · Border/Export Gateway + 7 isolated remote markets (DBSCAN noise) |
| products | Cereal · Legume · Vegetable · Fruit · Root & Tuber · Cash Crop · Livestock Product |
| baskets | "Shopping missions": breakfast, staples, pilau, snacks, household, fresh veg, baby (grocery); maize planting, crop protection, dairy, horticulture, poultry, potato, tools, top-dressing (agro) |
