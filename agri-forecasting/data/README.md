# Data dictionary

All files are **synthetic** and fully reproducible: `python src/agrilab.py` regenerates them byte-for-byte
(seeds are fixed in `src/agrilab.py`). Read that file to see exactly how each series is built.

## `market_prices_daily.csv`  (35,732 rows)
| column | type | meaning |
|---|---|---|
| `date` | date | 2015-01-01 … 2024-12-31 (Sundays absent: markets closed) |
| `market` | str | `Central`, `Highland`, `Harbor` |
| `commodity` | str | `maize`, `tomato`, `onion`, `potato` |
| `price_per_kg` | float | wholesale price per kg, local currency units |
| `volume_tonnes` | float | tonnes traded that day; moves inversely with price (elasticity ≈ -1.2) |
| `fuel_index` | float | transport-cost index, 100 at start (shared by all series) |

Built-in features of the generator (so you can check what your models find):
* **Trend**: 7-9 % annual log-growth depending on crop.
* **Seasonality**: yearly cycle with a secondary harmonic; peak month differs by crop (tomato ≈ March-April, maize ≈ May-June, ...).
* **Rain driver**: heavier rain ~2 months earlier lowers prices (more supply); crop-specific sensitivity.
* **Fuel driver**: small positive effect.
* **Shocks**: 3-5 per crop (rise fast, decay slowly) + a shared "transport disruption" in spring 2020.
* **Market effects**: `Central` = reference, `Highland` ≈ 12 % cheaper and noisier, `Harbor` ≈ 12 % dearer.
* **Planted messiness**: random missing days (3 % / 7 % / 4 % by market), two multi-week Highland outages
  (2017-03-06..24 and 2021-08-02..20), and **7 decimal-slip outliers** in `Highland` (price x10 or x0.1).

## `weather_daily.csv`  (3,653 rows)
| column | meaning |
|---|---|
| `date` | daily, 2015-2024 |
| `rainfall_mm` | daily rainfall; two rainy seasons per year (peaks ~April and ~October); year-to-year anomalies |
| `temp_c` | daily mean temperature |

## `leaf_disease_synthetic.npz`
`X` uint8 `(2400, 48, 48, 3)`, `y` int `(2400,)`, `class_names` = `healthy, leaf_spot, blight, rust` (600 images each).
Generated by `ag.make_leaf_dataset`.  Real-world equivalent: the public **PlantVillage** dataset (see Lesson 8.7, section 8).
