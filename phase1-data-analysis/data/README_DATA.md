# Data guide

> ⚠️ **All data are SYNTHETIC.** They are generated by `generate_datasets.py` (fixed seed → identical files for everyone).
> They imitate the *structure and rhythm* of Kenyan agricultural markets: two rainy seasons, the 2021–22 drought, food inflation,
> retail premiums in cities, but they are **not official statistics**. Market coordinates and county populations are approximate.
> Never quote these numbers as facts about Kenya.

| File | Format | Rows | Used in |
|---|---|---|---|
| `market_prices_clean.csv` | CSV | 15,048 | lessons 1–3, 5–8 (tidy teaching version) |
| `market_prices_raw.csv` | CSV | 15,093 | lesson 4, **capstone** (real-world mess included) |

> 🔎 **Raw files contain real-world problems.** Finding, counting and fixing them is part of the work (Lesson 4 and the capstone).
> Don't assume any file is clean until *you* have checked it.

## `market_prices_*.csv`: weekly market prices
**One row = one price observation: one crop, in one market, on one Monday.**

| Column | Meaning | Unit / format |
|---|---|---|
| `record_id` | identifier of the observation | `R000001` … |
| `date` | Monday of the observation week | `YYYY-MM-DD` |
| `recorded_at` | time the enumerator logged the price | `YYYY-MM-DD HH:MM:SS`, East Africa Time |
| `crop` | commodity | Maize, Beans, Potatoes, Tomatoes, Kale, Cabbage, Onions, Bananas |
| `market` | market name | 10 markets (6 wholesale, 4 retail) |
| `county` | county of the market | 9 counties |
| `price_kes_per_kg` | price paid | Kenya shillings per kilogram |
| `price_unit` | unit stated by the reporter | expected: `KES/kg` |
| `volume_kg` | quantity traded in that week | kilograms |

Coverage: 4 years (2021-01-04 → 2024-12-30, 209 weeks). Wholesale markets report all 8 crops; retail markets report 6.

## `production_by_county.xlsx`
* **Sheet `production`**: *title rows sit above the header* (use `skiprows`). Columns: `county`, `crop`, `year`, `area_ha` (hectares), `production_tonnes`. **One row = one county × crop × year.**
* **Sheet `counties`**: `county`, `region`, `population_2019` (approximate).

## `markets.json`: nested
One record per market: `market`, `county`, `type` (`wholesale`/`retail`), `location` → `{lat, lon}`, `opens` → `{days, hour}`, `crops_traded` (a list).
Flatten with `json.load` + `pd.json_normalize`.

## `weather_monthly.json`: flat records
`county`, `year`, `month`, `rainfall_mm` (millimetres), `avg_temp_c` (°C). **One row = one county × month.**

## `dairy_farms.csv`: cross-sectional survey (no data dictionary supplied on purpose!)
Lesson 8 asks you to *infer* the meaning of each column from its name and verify it: as you would with an unfamiliar file at work.

## Regenerating
```bash
cd data
python generate_datasets.py
```
Changing `SEED` in the script produces a different (but equally structured) set of files. Note that the auto-check answers in
`course_answers.json` belong to the shipped seed (2024).
